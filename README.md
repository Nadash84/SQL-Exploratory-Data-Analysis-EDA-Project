# SQL Exploratory Data Analysis (EDA) Project

## Overview

This project demonstrates the use of SQL for Exploratory Data Analysis (EDA) on a sales dataset. The goal was to explore the database, understand the data structure, analyse key business metrics, and uncover insights related to customers, products, and sales performance.

## Dataset

The dataset contains sales transaction data, customer information, and product details. It was structured using a data warehouse model with fact and dimension tables to support efficient analysis.

## Tools Used

* SQL Server
* SQL Queries
* GitHub
* Data Warehouse (Fact & Dimension Tables)

## Analysis Steps

1. Explored the database structure, schemas, tables, and columns.
2. Investigated customer, product, and sales dimensions.
3. Analysed date ranges and order history.
4. Explored key business measures such as sales, quantity, and pricing.
5. Identified top-performing and low-performing products and customers.
6. Applied aggregation, filtering, grouping, and ranking techniques to generate insights.

## Key Analysis Areas

### Database Exploration

* Reviewed database schemas and table structures.
* Examined relationships between fact and dimension tables.

### Dimension Exploration

* Analysed customer and product attributes.
* Investigated categories and subcategories.

### Date Exploration

* Identified first and last order dates.
* Measured the overall sales period covered by the dataset.

### Measures Exploration

* Calculated total sales, order counts, and product performance metrics.
* Analysed business performance using aggregate functions.

### Ranking Analysis

* Identified Top N and Bottom N products and customers.
* Compared performance across categories and segments.

## Results

The analysis provided insights into sales trends, customer behaviour, product performance, and overall business activity. SQL queries were used to transform raw data into meaningful information that supports data-driven decision-making.

## Skills Demonstrated

* SQL Query Writing
* Data Exploration
* Exploratory Data Analysis (EDA)
* Data Aggregation
* Ranking and Window Functions
* Business Insight Generation
* Data Warehouse Analysis

## How to Run

1. Import the dataset into SQL Server.
2. Create the required database tables.
3. Load the data into fact and dimension tables.
4. Execute the SQL queries included in the project.
5. Review the results and insights generated from the analysis.
